# 📚 StudyBuddy
**StudyBuddy** adalah aplikasi web berbasis HTML, CSS, dan JavaScript yang dirancang untuk membantu mahasiswa dalam mengatur waktu belajar,
menyusun daftar tugas, serta merencanakan studi secara efisien. Dengan tampilan futuristik dan antarmuka ramah pengguna, aplikasi ini cocok
digunakan sebagai asisten digital untuk produktivitas belajar.

## ✨ Fitur Utama
### 🔹 Splash Screen
Tampilan awal saat pengguna membuka aplikasi, memberikan kesan profesional dan modern.
### 🔹 Onboarding
Terdiri dari 3 halaman penjelasan singkat mengenai fitur-fitur aplikasi sebelum pengguna masuk ke halaman login.
### 🔹 Login Page
Form login sederhana yang mengarahkan pengguna ke halaman utama aplikasi.
### 🔹 Beranda
Menampilkan kumpulan video pembelajaran yang disimpan oleh mahasiswa untuk mempermudah akses materi kuliah.
Berfungsi sebagai halaman "index" atau dashboard utama.
### 🔹 Daftar Tugas
Fitur To-Do List yang memungkinkan pengguna:
- Menambahkan tugas baru.
- Menandai tugas sebagai selesai (dengan pop-up konfirmasi).
- Mengedit tugas.
- Menghapus tugas.
- Tugas selesai otomatis berpindah ke **Riwayat Tugas**.
### 🔹 Riwayat Tugas
Menampilkan daftar tugas-tugas yang telah ditandai selesai oleh pengguna. Memudahkan pelacakan progres belajar.
### 🔹 Study Planner
Pengguna dapat merencanakan jadwal belajar dengan memilih:
- Tanggal
- Hari
- Waktu
- Mata pelajaran  
Semua rencana akan ditampilkan dalam **tabel** yang rapi dan mudah dibaca.
### 🔹 Profil
Halaman profil dengan tampilan foto profil di tengah layar. Pengguna bisa:
- Melihat dan mengedit informasi profil.
- Mengedit langsung tanpa keluar dari aplikasi (tanpa reload).


## 🛠 Teknologi yang Digunakan
- **HTML5** – Struktur halaman.
- **CSS3** – Styling responsif dan menarik.
- **TailwindCSS-like styling** – Dengan class utility untuk mempercepat desain.
- **JavaScript (Vanilla)** – Menangani interaksi dan logika antar halaman.

## 🧭 Alur Navigasi
Di dalam `beranda.html`, terdapat navigasi untuk:
- Beranda
- Daftar Tugas
- Riwayat Tugas
- Study Planner
- Profil


## 📁 Struktur File
